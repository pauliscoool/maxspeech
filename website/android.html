Download MaxSpeech for Android

  1. On your phone, tap Download MaxSpeech for Android (or scan the QR from a computer).
  2. If Chrome blocks the file: tap the download → Open → allow this browser to Install unknown apps.
  3. Tap Install. When it finishes, open MaxSpeech.
  4. Sign in with your MaxSpeech account, then allow Microphone, Display over other apps, and Accessibility (that last one is how text pastes into Gmail, WhatsApp, Chrome…).
  5. Hold the glass capsule and speak. Release to enhance and paste.

Install won’t start?

  • Unknown sources — Settings → Apps → special app access → Install unknown apps → enable for Chrome / Files.
  • Play Protect — “Blocked by Play Protect” can appear on a first sideload. Tap More details → Install anyway.
  • File is tiny / missing — use the GitHub build: Actions → Android APK and download the MaxSpeech-android artifact, or the latest Release.
  • Overlay / Accessibility — those are optional for in-app dictation. You only need them to paste into other apps.
