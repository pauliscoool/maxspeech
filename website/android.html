Download MaxSpeech for Android

Version 0.1.3 — tap to install on this phone

  1. On your phone, tap Download MaxSpeech for Android (or scan the QR from a computer).
  2. If Chrome blocks the file: tap the download → Open → allow this browser to Install unknown apps.
  3. Tap Install. When it finishes, open MaxSpeech.
  4. Sign in, then allow Microphone and Display over other apps. For Accessibility on a sideloaded app: Settings → search Apps → MaxSpeech → top-right ⋮ Allow restricted settings (not Clear cache). Then Accessibility → MaxSpeech on → go back and Proceed. Turn off Wispr Flow / Whisper Flow Accessibility while using MaxSpeech.
  5. Hold the glass capsule and speak. Release to enhance and paste.

Install won’t start?

  • Unknown sources — Settings → Apps → special app access → Install unknown apps → enable for Chrome / Files.
  • Play Protect — “Blocked by Play Protect” can appear on a first sideload. Tap More details → Install anyway.
  • Download didn’t start — use the direct file: MaxSpeech.apk
  • Overlay / Accessibility — needed to paste into other apps. If Accessibility is greyed out: Apps → MaxSpeech → ⋮ Allow restricted settings. Don’t tap Clear cache.
