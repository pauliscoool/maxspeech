Download MaxSpeech for Windows

  1. Open the downloaded installer (full setup with WebView2 embedded).
  2. If SmartScreen appears: More info → Run anyway. This is the #1 reason a second PC looks like “it won’t install.”
  3. Click through the wizard (Install / Add). It installs under your user folder (%LOCALAPPDATA%\MaxSpeech) and may open MaxSpeech when finished. To remove it later, use Windows Settings → Apps → MaxSpeech → Uninstall — do not pick Uninstall inside the setup wizard if you only meant to remove it.
  4. Windows needs WebView2 (the installer embeds the bootstrapper if it’s missing — that step needs internet).
  5. Sign in (or Continue locally), then hold Ctrl + Win to dictate.

Won’t install on another PC?

Microphone, headphones, USB audio, and “connectors” do not block install. Those only matter after MaxSpeech is running. Same for Wi‑Fi/firewall except when WebView2 must download.

  • SmartScreen (“Windows protected your PC”) — click More info, then Run anyway. Choosing Don’t run looks like the installer “doesn’t open.”
  • File disappears after download — Windows Defender may have quarantined it. Check Windows Security → Protection history and restore MaxSpeech_x64-setup.exe.
  • File should be a large installer — the full package embeds WebView2 so a clean PC can install offline. If your download is only a few KB, delete it and download again.
  • WebView2 error during setup — go online, install WebView2 Runtime, then re-run the MaxSpeech installer.
  • Installer finished but no window — open the system tray (∧), look for MaxSpeech, or run %LOCALAPPDATA%\MaxSpeech\maxspeech.exe from File Explorer.
  • Needs 64-bit Windows (x64) — this build won’t run on 32-bit Windows.
