Download MaxSpeech for Windows

  1. Open the downloaded .exe (~6 MB).
  2. If SmartScreen appears: More info → Run anyway.
  3. Finish the installer. Windows needs WebView2 (the installer embeds the bootstrapper if it’s missing).
  4. Open MaxSpeech and sign in, then hold Ctrl + Win to dictate.
