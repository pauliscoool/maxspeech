Or download .deb

  1. Make it executable, then run: 
    chmod +x MaxSpeech_*_amd64.AppImage
./MaxSpeech_*_amd64.AppImage
  2. Or install the Debian package: 
    sudo dpkg -i maxspeech_*_amd64.deb
sudo apt-get install -f
  3. If the AppImage fails with a FUSE error, try: 
    ./MaxSpeech_*_amd64.AppImage --appimage-extract-and-run
  4. Prefer an X11 session for global hotkeys and paste.
  5. Hold Ctrl + Shift + Space to dictate. Release to type.
